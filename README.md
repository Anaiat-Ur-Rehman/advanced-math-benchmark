# Advanced Math & Calculus Reasoning Evaluation

### Overview
This project focuses on assessing AI models on complex mathematical reasoning, advanced calculus, algebra, and multi-step problem solving.

### Key Components
* **Golden Trajectories:** Developed expert-verified, step-by-step solution paths for complex calculus and algebra problems.
* **Formula Application Check:** Verified whether the AI model selects and applies the correct mathematical theorems and formulas.
* **Logical Flow Audit:** Evaluated the intermediate steps of complex equations to ensure rigorous logical consistency.
